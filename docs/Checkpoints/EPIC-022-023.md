## Notes for whoever picks this up

- **Read a tree, never a directory.** A directory walk cannot answer for a bare
  repository, a commit nobody checked out, or the ninety-nine per cent of
  history that is not the working tree.
- **Nothing here opens a file, and that is load-bearing.** The object id and the
  size both come from the tree. It is also why this Epic has no content-safety
  surface — which stops being true at EPIC-024.
- **A content hash names its algorithm.** `git-blob:<oid>`, because a Git object
  id is `sha1("blob <length>" + NUL + bytes)` and is not comparable with
  anything else called a hash.
- **Do not recompute the hash from the working copy.** Different line-ending
  settings would make two developers' identical files look like two versions.
- **File identity is repository + path, and it must stay that way.** EPIC-020
  chose it for files seen in history. If anything ever chooses differently,
  every file in Ferret exists twice — and nothing fails, there are simply twice
  as many.
- **Only the mode distinguishes a symlink from a file.** The `type` column says
  `blob` for both.

## Next step

**EPIC-031 — Incremental Indexing.** Everything upstream of storage now exists:
repositories, worktrees, branches, commits, developers, files and file versions,
all as canonical entities with relationships and evidence, from a real provider,
selected by capability.

Three things are waiting there, and all three are recorded rather than
discovered:

1. **The relationship-identity problem (EPIC-018 §8).** Relationship identity
   includes `validFrom`, so re-emitting an unchanged structural edge at a later
   instant produces a new id. Ingestion must treat an open interval with
   identical endpoints and metadata as a no-op, or storage grows without bound
   for content that never changed. This is the single most important thing in
   the backlog.
2. **What "incremental" means.** `since` for history, and a content-hash
   comparison for files. Both exist; nothing yet decides when to use them.
3. **The working directory.** Everything so far reads committed state. "What am
   I working on right now" needs the other kind of read.

After that the slice reaches retrieval (**EPIC-052/053**), context packs
(**EPIC-060/061**) and MCP (**EPIC-065**) — at which point Ferret is usable
end to end.
