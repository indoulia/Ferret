## Notes for whoever picks this up

- **Never write to stdout from anything the MCP path can reach.** stdout *is*
  the transport. Ferret's logger has gone to stderr since EPIC-001 for this
  reason, and the failure path is asserted.
- **Estimates, not counts.** Adopting a tokenizer would tie Ferret to a model
  family, and the AI client is a provider like any other. The estimate
  over-counts deliberately: the failure modes are not symmetric.
- **Frame content; do not filter it.** A message discussing prompt injection is
  indistinguishable from one attempting it. Structured values, a notice that
  comes first, and no template with a hole for source text.
- **A pack must never lie about being complete.** Three omission reasons, each
  named in the pack.
- **When a fix does not work, ask the measurement rather than argue with it.**
  The first trimming implementation computed an allowance from an assumed
  characters-per-token ratio and produced an item that still did not fit.

  spawn the process → **EPIC-068**, **EPIC-058**
- No configuration or administration tools; an AI client can only read →
  **EPIC-066**, **EPIC-067**, **EPIC-069**
- Selection is search relevance alone — no freshness or authority weighting →
  **EPIC-057**, **EPIC-062**
