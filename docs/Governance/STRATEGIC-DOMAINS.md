# Ferret Strategic Domains

**Status: APPROVED**  
**Version: 1.0**  
**Effective: 2026-08-30**

Strategic Domains group related functional Epics. They are organizational boundaries, not implementation units. Functional Epics remain the unit of delivery, testing, validation, and completion.

## Domains

1. Foundation & Runtime
2. Configuration & Provisioning
3. Canonical Knowledge Model
4. Provider Platform
5. Source Discovery & Git
6. File Intelligence
7. Code Intelligence
8. Engineering Context
9. Session & Agent Memory
10. Evidence & Provenance
11. Knowledge Graph & Relationships
12. Search & Retrieval
13. Context Compilation
14. AI Control Plane & MCP
15. External Project Knowledge
16. Synchronization & Reconciliation
17. Security & Authorization
18. Storage & Data Lifecycle
19. Reliability & Operations
20. Evaluation & Quality
21. Distribution & Developer Experience

## Rules

- A domain does not itself represent a delivery commitment.
- A functional Epic must have independently testable acceptance criteria.
- An Epic may cross domain boundaries when that is the smallest coherent capability.
- No fixed number of Epics is required.
- Do not split Epics artificially merely to increase count.
- Do not combine unrelated capabilities merely to reduce count.
- The correct granularity is the smallest independently valuable, independently governable, independently testable capability.
